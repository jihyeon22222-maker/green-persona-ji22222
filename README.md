# green-persona-ji22222
환경재단 그린리더 발굴

## 프로젝트 개요
NVIDIA의 대규모 한국어 합성 페르소나 데이터셋(`Nemotron-Personas-Korea`)에서 환경 관련 가치관·관심사가 뚜렷한 인물을 추출해, 환경재단이 협업하거나 캠페인에 초대할 수 있는 "그린리더" 후보군을 발굴하고, 각 후보에게 맞는 캠페인 아이디어를 설계한다.

## 데이터 소스
- **데이터셋**: [nvidia/Nemotron-Personas-Korea](https://huggingface.co/datasets/nvidia/Nemotron-Personas-Korea)
- **규모**: 100만 행, 26개 필드 (직업/스포츠/예술/여행/음식/가족 페르소나, 인구통계·지리 정보 등)
- **라이선스**: CC BY 4.0
- **로컬 경로**: `Nemotron-Personas-Korea/data/*.parquet` (약 1.98GB, 9개 파일)
- **조회 도구**: DuckDB CLI로 parquet 파일을 직접 SQL 조회

## 그린리더 선정 기준
1. **지역 필터**: `province = '서울'` (서울 거주자 185,228명)
2. **키워드 필터**: `hobbies_and_interests`, `career_goals_and_ambitions`, `persona`, `cultural_background`, `skills_and_expertise` 필드에서 다음 키워드 매칭
   - 친환경, 환경보호, 환경운동, 탄소(중립/배출/포집), 재활용, 순환(경제/생산), 제로웨이스트, 플로깅, 분리수거, 기후(변화/위기)
   - 단순 채식/비건 언급처럼 건강·취향 목적으로 보이는 매칭은 제외하여 오탐(false positive) 최소화
3. **다양성 큐레이션**: 매칭된 913명 중 연령대(20대~60대)·성별·직업군(전문 기술직, 임원, 자영업, 취업준비생 등)이 고르게 분포하도록 10명 선정

## 캠페인 아이디어

### 1. "1인 1기술 재능기부" — 전문가 실무 매칭형
**대상**: 문영무, 김정미, 염종한, 박강은, 김형근, 정현진
각자의 실무 기술을 환경재단 프로젝트에 단발성으로 투입하는 프로보노 매칭. 저탄소 건축 자문, 친환경 소재 전환 클리닉, 제로웨이스트 배출 진단, 도시재생 시민 강좌 등.

### 2. "기후를 말하는 시간" — 시민 과학 커뮤니케이션
**대상**: 신병화
기후 데이터 전문가가 진행하는 팟캐스트/영상 콘텐츠. 위성 데이터 기반으로 이상기후 뉴스를 쉽게 풀어주는 정기 코너.

### 3. "그린 커리어 전환소" — 구직자 진로 연계
**대상**: 정재찬, 김정민
그린 산업(재활용센터, 친환경 건축·에너지 기업) 채용 수요와 구직자를 매칭. 경력 전환 코스 + 인턴십, 친환경 설계 공모전 등.

### 4. "가게 하나, 지구 한 뼘" — 소상공인 그린 전환
**대상**: 신선희
친환경 전환을 시도 중인 1인 사업자에게 재단이 인증 마크와 초기 전환 비용을 지원. 확산형 케이스 스터디로 활용.

**통합 브랜드 메시지**: "전문성으로 하는 환경운동" — 4개 캠페인을 하나의 시리즈로 묶어 운영.

## 시민 참여 콘텐츠: 분리수거 대작전
**파일**: `games/분리수거_대작전.html` (브라우저에서 바로 실행, 설치 불필요)
**플레이 주소 (GitHub Pages)**: https://jihyeon22222-maker.github.io/green-persona-ji22222/
- `main`에 게임 파일이 바뀌면 `.github/workflows/pages.yml`이 `games/build-pages.sh`로 `index.html`을 만들어 자동 배포한다.
- Pages 주소의 휴대폰 브라우저에서는 결과 화면의 **"결과 공유"** 버튼으로 결과 이미지를 인스타그램·카카오톡 등에 바로 보낼 수 있다. 공유 기능이 없는 브라우저와 Claude 아티팩트 화면에서는 **"이미지 저장"**으로 대신한다.

떨어지는 쓰레기를 6개 수거함(종이, 플라스틱, 캔·고철, 유리병, 비닐, 일반)에 알맞게 버리는 미니게임. 분리배출을 "외워야 하는 규칙"이 아니라 **틀려 보면서 자연스럽게 익히는 게임**으로 만든다.

### 기획의도
1. **가장 가까운 환경 행동**: 분리배출은 누구나 매일 하지만 영수증, 치킨 뼈, 깨진 유리컵처럼 헷갈리는 품목이 많아 선의로 잘못 버리는 경우가 많다. "제대로 버리는 법 알기"에 초점을 둔다.
2. **틀리는 게 곧 배우는 것**: 틀리면 바로 정답과 이유를 보여준다. 게임이 끝나면 틀린 품목만 모아 버리는 법을 정리해 준다.
3. **짧고 가볍게**: 한 판 2~3분, 링크 하나로 바로 플레이. 38가지 쓰레기가 한 번씩만 나오고, 지구 체력이 남은 채로 끝까지 버티면 클리어. 콤보, 효과음, 최고 점수, 결과 이미지 저장으로 재도전과 공유를 유도한다.
4. **캠페인 연결**: 행사 부스, SNS 공유, 교육 자료 등 시민 참여용 콘텐츠로 활용한다. "전문성으로 하는 환경운동" 메시지와 연계해 김형근(폐기물 처리 기술자) 후보의 제로웨이스트 진단 캠페인과 함께 소개할 수 있다.

**대상**: 분리배출이 헷갈리는 일반 시민, 특히 게임에 익숙한 10~30대와 교육용으로 활용할 초·중학생.

**내용 기준**: 환경부 재활용품 분리배출 가이드라인을 바탕으로 작성. 세부 기준은 지자체마다 다를 수 있어 게임 안에 안내 문구를 넣었다. 게임 특성상 투명 페트병·종이팩 전용 수거함은 생략하고 캔과 고철은 한 통으로 합쳤다.

## 성과 보고서 뷰어: 푸른발자국 VOL.23
**파일**: `reports/index.html` (성과 페이지) · **주소 (GitHub Pages)**: https://jihyeon22222-maker.github.io/green-persona-ji22222/reports/

- 성과 페이지의 책장에 놓인 보고서 표지를 누르면 표지가 화면 가운데로 날아와 책처럼 펼쳐지고, 한 장씩 넘기며 읽을 수 있다.
- 넘기는 법: 페이지 모서리 끌기, 페이지 누르기, 휴대폰에서는 옆으로 밀기, ← → 방향키, 아래 화살표 버튼과 슬라이더. 넓은 화면은 두 쪽 펼침, 휴대폰 세로 화면은 한 쪽씩 보여 준다.
- 쪽 이미지: 원본 PDF(표지 1장 + 펼침면 29장 + 뒤표지)를 낱장 60쪽으로 잘라 `reports/green-step-vol23/pages/01.webp`~`60.webp`에 두었다. 원본 PDF도 같은 폴더에 있어 뷰어에서 내려받을 수 있다.
- 책장 넘김은 [StPageFlip](https://github.com/Nodlik/StPageFlip)(MIT)을 `reports/vendor/`에 넣어 쓴다.
- 새 보고서를 추가하려면 쪽 이미지를 `reports/<보고서-id>/pages/`에 같은 이름 규칙으로 넣고, `reports/index.html`의 `REPORTS` 목록에 한 줄 추가하면 책장에 표지가 하나 더 생긴다.
