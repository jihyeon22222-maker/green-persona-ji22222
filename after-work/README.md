# 퇴근하고 뭐하지?

퇴근 직전의 체력·예산·귀가 시간을 고르면 오늘의 퇴근 후 코스를 랜덤으로 처방해 주는 작은 웹서비스입니다.
외부 API·로그인·DB 없이 정적 파일만으로 동작합니다.

## 실행

```bash
cd after-work
npx http-server -p 8080   # 또는 python3 -m http.server 8080
```

브라우저에서 http://localhost:8080 을 열면 됩니다. (`index.html`을 바로 열어도 동작합니다.)

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 선택 화면 / 결과(처방전) 화면 마크업 |
| `styles.css` | 밤 분위기의 모바일 우선 스타일, 애니메이션 |
| `data.js` | 활동·귀가 후 한 줄·코멘트 데이터 (여기만 고치면 코스 문구를 늘릴 수 있음) |
| `app.js` | 코스 생성 로직과 화면 동작 |

## 코스 생성 규칙

- 18:10 `회사 탈출`로 시작해서 `집으로 귀환`으로 끝납니다.
- **체력**에 따라 일정 개수(10% → 1개, 100% → 3~4개)와 고를 수 있는 활동의 강도가 정해집니다.
- **예산**보다 비싼 활동은 빠지고, 예산에 딱 맞는 활동이 더 잘 뽑힙니다.
- **귀가 시간** 안에 이동 시간까지 포함해 들어오도록 배치하고, 안 맞는 일정은 뺍니다. 23시 이후까지 여유가 있을 때만 늦은 밤 활동이 나옵니다.
- `다시 뽑기`는 조건을 그대로 두고 직전과 다른 코스를 만듭니다.
